# 实现 ServerConnectionSession 八态、Admission saga 八步与恰好一次补偿、重连窗口与复制编排

session 拥有 Admission 管道、Session 建立与 Release 固定、授权对象绑定、重连窗口、终结执行与复制编排。它**不写**连接注册表、**不写** Admission Gate，只发类型化命令并等 ack。V1 无 Session Resume Token：跨连接重连必须重做通道认证与完整 Handshake；同连接内 Resync 不重新握手——两条路径在实现与测试上严格分开。

设计出处：`docs/specs/2026-08-28-mvp-csharp-host-design.md` §6.3、§6.6 的 session 段、§8.1 的时序与映射表、§9.1 的步骤 5–17。
