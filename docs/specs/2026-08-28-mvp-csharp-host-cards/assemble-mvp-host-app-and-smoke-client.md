# 组装可执行 lumio-mvp-host 与自带 SmokeClient，落实 CLI 契约与测试控制面门控

`App` 是全仓唯一组装根：显式 `new` 接线全部模块与队列，**无 DI 容器、无 service locator、无全局 EventBus**。`SmokeClient` 是独立可执行进程（不是库），因为 A1-α 要求**真跨进程**（`LocalSplitProcess` 形态）。测试控制面只在显式开关下装配、只绑回环、每次调用写 Audit。

设计出处：`docs/specs/2026-08-28-mvp-csharp-host-design.md` §4.1 的 App / SmokeClient 行、§6.5 的组装纪律、§7.4 的 ws 分档、§9.3 的进程 CLI 与测试控制面承载。
