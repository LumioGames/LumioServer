# 定义跨模块唯一契约面与 Audit/Diagnostic 最小写入面，并建立全局架构门禁

`HostContracts` 是全部跨模块协作的唯一契约层：所有 id / epoch 值类型、typed command 与 event、有界端口接口、`IWorldSimulationPort` 都在这里。事件端口集中在契约层后，「事件不产生反向边」成为机制保证而不是纪律。本卡同时建立 `Architecture.Tests`（分层、红线边、队列登记、缺席清单、禁用词表、Adapter 缺席仍全绿）与 `TestKit`，它们是后续每张实现卡的门禁。

设计出处：`docs/specs/2026-08-28-mvp-csharp-host-design.md` §4.1 / §4.2 / §4.3 / §6.0 / §6.1 / §6.2 / §6.3 / §6.4 / §6.5 / §6.6 / §9.3 / §15。

Produces（命名空间 `Lumio.Server.MvpHost.HostContracts` 与 `Lumio.Server.MvpHost.Observability`）:

- 全部 id / epoch 值类型、支撑类型、枚举、typed command/event、端口接口，签名逐字见设计 §6.1–§6.6；下游工程一律从本程序集消费，**不得自行重复定义**。
- `public interface IWorldSimulationPort : System.IDisposable { HostSimulationState State { get; } HostLifecycleResult Initialize(in HostSessionInit init); HostLifecycleResult Ready(); HostTickOutcome RunTick(in HostTickRequest request); HostLifecycleResult Drain(); HostLifecycleResult Snapshot(out System.ReadOnlyMemory<byte> opaqueSnapshot); }`
- `public readonly record struct HostTickRequest(LogicalTickToken Tick, System.ReadOnlyMemory<WireFrame> Ingress, ulong DeterministicSeed);`
- `public readonly record struct HostTickOutcome(HostTickStatus Status, LogicalTickToken Tick, System.ReadOnlyMemory<byte> StateHash, ulong AuthorityRevision, System.ReadOnlyMemory<WireFrame> Egress, HostFaultClass? FaultClass, string? StableErrorId);` —— `FaultClass` **必须可空**：`null` = 「无见证」，`None` = 「有正向见证且无故障」，两者在类型上必须可区分。非空枚举的 `default` 是 `0 == None`，会让「忘了填见证」静默变成「证明无故障」，绕过 ADR-006 原文「A caught failure without a `FaultClass` attestation defaults to `SlotStateUnproven`」这条从严红线（本仓 `modules/README.md` 同款表述）。`IFaultAdjudicator.Classify(HostFaultClass? witness)` 的入参因此有真实的 `null` 生产者。
