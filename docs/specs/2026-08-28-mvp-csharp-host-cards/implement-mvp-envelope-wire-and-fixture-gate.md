# 实现 MvpEnvelopeDocument、规范 JSON 编解码、结构层加语义层双校验与 permission gate 六项判定

架构源 C# 侧不存在 `ReplicationEnvelope` 类型定义（`Lumio.Gen.LanguageBinding` 只有名字映射），本仓又不得写第二套公共协议定义。本卡交付的是**架构源 schema 的 reader/writer，不是 definition**：字段名与取值域由镜像 schema 机器断言，`body` 保持 `JsonObject` 不生成任何 typed body POCO，并配自过期守卫使技术债有到期日。
