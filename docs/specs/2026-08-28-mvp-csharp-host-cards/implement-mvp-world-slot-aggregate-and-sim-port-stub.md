# 实现 WorldSlotHost 聚合根与 IWorldSimulationPort 参考存根

world-slot 是 Host 侧唯一聚合根，收权五项：Admission Gate 唯一所有权、生命周期 epoch、Quiesce 原子序列、pacing 启停、FaultClass 裁决。状态机真值取镜像 fixture（含 `Faulted` 与 `anyActiveTo`），生成表只作前向迁移交叉校验。C# 侧的迁移建模是**两份独立集合**：15 条前向迁移表 + 一条覆盖 11 个活动态的 `anyActiveTo` 规则。同卡交付 `IWorldSimulationPort` 的参考存根——它是 Runtime 缺位期的 production absence-filler，模型只有不透明 key→value 覆盖表加单调 `AuthorityRevision`，零 ECS / Voxel / Gameplay 词汇；它同时实现 `HostContracts` 的 `IWorldMutationSink`，为 A1-α 的带外测试控制面提供**只入队、由 Owner Thread 在下一次 `RunTick` 开头应用**的世界变更入口。

设计出处：`docs/specs/2026-08-28-mvp-csharp-host-design.md` §4.3（断言机制纪律）/ §6.4 / §6.5 / §6.6 / §9.3（服务端 trace）。
